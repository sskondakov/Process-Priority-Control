# Контроль приоритета процессов 1.0

Небольшая утилита для Windows, которая висит в трее и автоматически выставляет
приоритеты процессов по заданным правилам. Написана на Free Pascal (WinAPI, без LCL).

## Возможности

- Правила по имени процесса (например, `chrome.exe`).
- Для каждого правила задаются:
  - **приоритет CPU** — от «Низкий» до «Реального времени»;
  - **приоритет I/O** — от «Очень низкий» до «Высокий»;
  - **приоритет памяти** — от «Очень низкий» до «Обычный»;
  - **фильтр по памяти** — применять правило, только если процесс занимает не менее N Мбайт (0 — без фильтра).
- Пункт «Не менять» оставляет соответствующий приоритет как есть.
- Пункт «По умолчанию» возвращает приоритет, который был у процесса при старте: он запоминается по имени процесса при первом обнаружении, до любых изменений (пока программа запущена). Так можно задать два правила: общее с «По умолчанию» и ниже него правило с фильтром по памяти — приоритет будет переключаться в обе стороны.
- Периодический опрос процессов с настраиваемым интервалом (по умолчанию 30 с, максимум 3600 с).
- Иконка в трее с меню, окно настроек с таблицей правил. В подсказке иконки — название программы, а если в журнале есть ошибки, под ним «имя процесса - ошибка» для последней из них. В журнале все изменения процесса за проход пишутся одной строкой, например «Изменены приоритеты chrome.exe (PID 123, 1024 Мбайт): «CPU» Обычный (2) → Низкий (0), ...». Если объём памяти процесса измерить не удалось, это записывается как ошибка, а приоритеты этого процесса в данный проход не меняются.
- Журнал работы `PPControl.log` рядом с программой (не более 1024 строк): обнаружение процесса с его приоритетами по умолчанию, изменения приоритетов, ошибки чтения и изменения. Если приоритет прочитать не удалось, он считается обычным. Открывается пунктом меню «История работы».
- Автозагрузка вместе с Windows (`HKCU\...\Run`).

## Хранение настроек

- Правила — CSV-файл `%APPDATA%\PPControl\rules.csv`
  (`Process;CpuPriority;IoPriority;MemoryPriority;MinMemoryMB`).
- Интервал опроса и служебные флаги — реестр `HKCU\Software\PPControl`.

## Сборка

Нужен Free Pascal 3.2.2 (входит в Lazarus, путь по умолчанию `C:\lazarus\fpc\3.2.2\bin\x86_64-win64`;
если его нет, используется `fpc` из `PATH`).

```cmd
build.cmd
```

Скрипт собирает ресурсы (`res\resources.rc`) и компилирует `PPControl.lpr` в `PPControl.exe`.

## Структура

| Файл | Назначение |
|------|------------|
| `PPControl.lpr` | точка входа, трей, главный цикл и таймер |
| `PriorityEngine.pas` | применение приоритетов CPU / I/O / памяти |
| `AppStorage.pas` | правила, CSV, реестр, автозагрузка |
| `SettingsWindow.pas` | окно настроек |
| `AppLog.pas` | журнал работы |
| `AboutWindow.pas` | окно «О программе» |
| `ToolbarIcons.pas` | иконки панели инструментов |
| `res/` | иконки, манифест, файл ресурсов |

## Примечания

- Для изменения приоритетов чужих процессов может потребоваться запуск от имени администратора.
- Приоритет «Реального времени» может сделать систему неотзывчивой — используйте осторожно.
- Готовый `PPControl.exe` в репозиторий не входит (см. `.gitignore`), его нужно собрать.
